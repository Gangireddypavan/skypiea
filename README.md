# 🛩️ Skypiea Jets - Luxury Aviation Reimagined

**Skypiea Jets** is a high-end, immersive digital platform for boutique luxury private aviation. Built with a focus on visual excellence and seamless interactions, it showcases a world-class fleet through cinematic animations and a premium glassmorphic interface.

![Skypiea Jets Showroom](file:///d:/AI%20Project/jesko%20jets/public/fleet/g650er.jpg)

## ✨ Premium Features

- **120-Frame Hero Sequence**: A custom-engineered, scroll-triggered canvas animation that creates a cinematic "fly-through" experience as you enter the site.
- **Immersive Aircraft Detail View**: A sophisticated modal experience featuring a "boarding sequence" transition from exterior to luxury interior visuals.
- **Micro-Interactive Fleet Gallery**: A high-performance grid with hover-reveal technical specifications and premium glassmorphism.
- **Bespoke Interiors Showcase**: Dedicated high-impact cinematic sections highlighting the craftsmanship and materials of the fleet.
- **Smooth Navigation & Motion**: Powered by **Lenis** for smooth-as-silk scrolling and **Framer Motion** for refined micro-animations.
- **High-Conversion Booking**: Integrated, context-aware CTAs and a sleek booking form for a frictionless reservation flow.

## 🚀 Tech Stack

- **Next.js 16** - The world's most advanced React framework.
- **TypeScript** - For industrial-grade type safety and reliability.
- **Tailwind CSS** - Custom design system for consistent, premium aesthetics.
- **Framer Motion** - Cinematic animation orchestration.
- **Lenis** - High-frequency smooth scrolling engine.

## 📁 Architecture

```text
app/              # Next.js 16 App Router pages & layouts
components/       # Modular React components
  ├── booking/    # Contact forms & floating CTAs
  ├── fleet/      # Aircraft gallery, cards, & detail modals
  ├── hero/       # Scroll-triggered canvas sequence
  └── layout/     # Glassmorphic navbar & footer
lib/              # Performance-optimized utilities & fleet data data
public/           # 4K assets, animation sequences, & interior visuals
```

## 🛠️ Performance & Scalability

The project is optimized for **Core Web Vitals**:
- **Image Optimization**: Sophisticated handling of high-resolution aviation imagery.

## 📦 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone and install dependencies
git clone https://github.com/your-repo/skypiea-jets.git
cd skypiea-jets
npm install
```

### Development
```bash
# Start the premium development experience
npm run dev
```

### Production
```bash
# Build for industrial-grade deployment
npm run build
npm run start
```

## 🌐 Deployment

The platform is optimized for [Vercel](https://vercel.com). Simply connect your repository and Vercel will handle the rest with zero-config optimization.
